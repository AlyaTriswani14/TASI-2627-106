## Ringkasan

Penelitian ini menguji efektivitas *large language model* terpandu *retrieval* atas taksonomi resmi (KBLI 2025) dalam menstandardisasi data administratif UMKM, serta dampaknya terhadap kualitas data dan kinerja tugas pengambil keputusan di pemerintah daerah. Menggunakan paradigma *design science research*: prinsip desain dirumuskan dari teori kualitas informasi dan bukti lapangan, diinstansiasikan sebagai purwarupa, lalu diuji lewat lima hipotesis (eksperimen standardisasi, kualitas data sebelum/sesudah, dan evaluasi pengguna). Abstrak lengkap ada di `Dokumen/proposal/Header/abstrak.tex`.
