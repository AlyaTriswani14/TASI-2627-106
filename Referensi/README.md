## Struktur

`Referensi-Proposal/` memuat 71 PDF aktif bernomor IEEE dan paket `referensi.zip`. `NonAktif/` menyimpan literatur di luar koleksi utama, bibliografi arsip, `Arsip Koleksi/`, serta `Versi Lain/`. Folder `entri-aktif` dan empat Markdown indeks lama telah digantikan oleh struktur serta halaman ini.

Halaman HTML dapat dibuka langsung tanpa server atau internet. Pertahankan struktur folder agar tautan lokal tetap berfungsi. Tautan DOI/penerbit memerlukan internet. Berkas utama bibliografi tetap [references.bib](../Dokumen/proposal/references.bib).
