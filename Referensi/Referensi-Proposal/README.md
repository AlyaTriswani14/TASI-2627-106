# PDF referensi proposal

Koleksi aktif per 19 November 2026 berisi **71 PDF**, bernomor `01`–`71` sesuai urutan IEEE proposal.

Buka **[Referensi-Proposal.html](../Referensi-Proposal.html)** untuk mencari sumber, membaca ringkasan, membuka matriks sitasi, dan mengisi checklist bacaan. Paket [referensi.zip](referensi.zip) memuat 71 PDF dengan nama yang sama.

Metadata utama tetap berada di [references.bib](../../Dokumen/proposal/references.bib). PDF di luar koleksi utama tersedia melalui [Nonaktif](../Referensi-Proposal.html#nonaktif).
