# Referensi nonaktif

Koleksi ini berisi **40 berkas**: 33 PDF, 4 BibTeX, dan 3 ZIP. Nama PDF mengikuti judul dokumen; keterangan edisi atau versi ditambahkan bila diperlukan untuk membedakan salinan.

- Folder utama: literatur dan dokumen yang bukan PDF utama dari 71 referensi proposal, serta bibliografi arsip.
- `Versi Lain/`: empat versi alternatif yang dipertahankan saat folder `entri-aktif` dikeluarkan dari repositori.
- `Arsip Koleksi/`: tiga paket koleksi lama; isi paket historis dipertahankan.

Gunakan [halaman referensi — Nonaktif](../Referensi-Proposal.html#nonaktif) untuk pencarian dan tautan langsung. Status nonaktif tidak berarti karya tidak relevan; sumber atau versi ini tidak dipakai sebagai PDF utama pada snapshot 19 November 2026.
